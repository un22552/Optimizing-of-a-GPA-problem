# GPA Optimization

整理的是一个固定成绩分布下的 GPA 达标人数最大化问题。成绩分布按固定比例生成（C− 到 A+ 共 9 档），学生在不同课程池中修读，优化目标是在满足每门课成绩槽位约束的前提下，使均绩 ≥ 阈值的达标学生人数最大化。

当前重点是**三专业多层交叉场景**：300 名学生分 3 个专业（G1=150, G2=100, G3=50），每人修 24–28 门课，课程分布在 9 个共享程度各异的池子中（公选、一二共修、二三共修、各专业独修）。详见 [PROBLEM.md](PROBLEM.md)。

精确 MILP 模型在 **CBC 求解器下可能跑不出结果**（分支定界长时间卡住），但换用 **HiGHS 求解器后 80 秒即可精确最优**。仓库同时保留了启发式搜索方案，适合快速探索和参数扫描。

## 环境

Python 3.11+，核心依赖：

```powershell
conda create -n gpa-opt python=3.11
conda activate gpa-opt
pip install -r requirements.txt
```

### 求解器选择（重要）

| 求解器 | 速度 | 安装 | 推荐场景 |
|--------|------|------|---------|
| **HiGHS** | ⚡ 快（80s 精确最优） | `pip install highspy` | **推荐默认使用** |
| CBC | 🐢 慢（>600s 超时） | PuLP 自带 | 备用 / 小规模问题 |

HiGHS 是开源的，一行安装即可：

```powershell
pip install highspy
```

`gpa-three-major.py` 默认使用 HiGHS。如需切回 CBC，修改文件末尾的 `prob.solve(pulp.HiGHS(...))` 为 `prob.solve(pulp.PULP_CBC_CMD(...))`。

## 运行示例

### 精确 MILP（推荐）

```powershell
# 默认阈值 3.5，HiGHS 求解器，600s 时限
python .\gpa-three-major.py
```

如需修改阈值或时限，在文件中修改 `solve(threshold=3.5, time_limit=600)` 的参数。

### 启发式快速扫描

```powershell
# 贪心模式，快速出结果
python .\gpa-three-major-heuristic.py --thresholds 3.5 --mode greedy --search 20 --scale 1.2

# swap 模式 + MILP 精修，质量更高
python .\gpa-three-major-heuristic.py --thresholds 3.5 --mode swap --search 120 --scale 1.8 --local-rounds 8 --local-beam 12 --local-mutations 24 --swap-size 4 --refine-top 10 --time-limit 30 --jobs 3
```

## 核心结果（阈值 T = 3.5）

### 理论天花板

基于总绩点资源的不等式 $p \le \frac{3.061 - 1.7}{T - 1.7}$，详见 [gpa_ceiling_proof.md](gpa_ceiling_proof.md)。

| 阈值 T | 天花板 |
|--------|--------|
| 3.3 | 85.06% |
| **3.5** | **75.61%** |
| 3.7 | 68.05% |
| 4.0 | 59.17% |

### 三专业场景精确解（HiGHS, SDP=1.0, 80s Optimal）

```
======  ======  ======  ==============================
整体     198/300  66.00%  天花板 75.61%（差距 9.61%）
G1      102/150  68.0%   24门/人（公选10+一二4+专一10）
G2       65/100  65.0%   24门/人（公选10+一二4+二三3+专二7）
G3       31/50   62.0%   28门/人（公选10+二三3+专三15）
======  ======  ======  ==============================
```

**解读**：

- 天花板 75.61% 是**不可达的理论上界**——推导假设每个达标学生恰好均绩 = 3.5，每个未达标学生恰好均绩 = 1.7，这两个极端在离散课程组合下几乎无法同时取到
- 主要瓶颈是 **A−/A/A+ 仅占总成绩槽位的 26%**，凑均绩 ≥ 3.5 对高分段消耗很大
- G3 最低（62%）：修课最多（28 门）但专业三仅有 50 人小池，高分槽位（A+ 仅 3×15=45 个总槽位中的 1-2 人份）极度稀缺
- G2 次之（65%）：专业课二 7 门×100 人，高分段随人数缩放较充裕
- G1 最高（68%）：专业课一 10 门×150 人，池子大且课多，组合灵活度最高

### 对比：碎片化场景 vs 无差异场景

| 场景 | 达标比例 | 距天花板 |
|------|---------|---------|
| 无差异 M=5 | 53.00% | 22.61% |
| 无差异 M=10 | 56.00% | 19.61% |
| **碎片化三专业** | **66.00%** | **9.61%** |

> 三专业碎片化场景的达标比例（66%）**高于**无差异模型（56%），且距天花板更近（9.61% vs 19.61%）。核心原因是每人 24-28 门课的组合灵活性远高于 5-10 门课，更大的 M 值更好地逼近了连续模型的假设。

## 求解性能对比

| 配置 | 求解器 | SDP | 变量数 | 时间 | 状态 |
|------|--------|-----|--------|------|------|
| 原始 | CBC | 1.0 | ~43K | >600s | **超时** |
| HiGHS + SDP=2.0 | HiGHS | 2.0 | ~38K | 42.7s | Optimal（近似，78.67% 偏高） |
| **HiGHS + SDP=1.0** | **HiGHS** | **1.0** | **~38K** | **80.2s** | **Optimal（精确，66.00%）** |

SDP 参数在 `gpa-three-major.py` 中控制 GPA sum 值的合并步长：

- `SDP = 1.0`：整数步长，精确 binning，保证阈值判断无误差（**推荐**）
- `SDP = 2.0`：偶数步长，变量约减少 11%，但可能高估达标人数（84 分以下的值被四舍五入到 84）

## 如何理解结果

1. **天花板 ≠ 可达最优**。天花板 $p_{\text{ceiling}} = \min(1, \frac{3.061-1.7}{T-1.7})$ 是纯资源约束下的理论上界，忽略了离散组合、跨池耦合、整数粒度等实际约束。

2. **精确 MILP 现在可用了**。换用 HiGHS 后，三专业场景 80 秒精确最优。但如果池子数或学生数大幅增加，模型仍可能膨胀。此时可先用启发式脚本快速探索。

3. **Not Solved 时谨慎解读**。如果 CBC 或低时限 HiGHS 返回 "Not Solved"，当前解可能是 LP 松弛的非整数解，不可直接当作可行解使用。`gpa-three-major-heuristic.py` 在 CBC 模式下包含整数性检查以避免此问题。

4. **建议工作流**：先用启发式快速扫描多个阈值 → 对关键阈值用 HiGHS 精确 MILP 验证 → 对照天花板公式理解差距来源。
